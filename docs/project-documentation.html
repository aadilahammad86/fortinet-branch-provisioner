The project in one minute

We are setting up Fortinet firewalls for our branch offices. A firewall is the box that gives a branch safe internet and Wi‑Fi, and protects the network.

We built the full setup on one firewall first. Then we saved every step as a script — a small program that repeats the same work automatically. Now, for each new branch, we run the script, answer two simple questions, and the firewall is ready in seconds instead of doing everything by hand.

The last plan is to join all branches to Head Office over a private, encrypted link (a VPN), so every office feels like one network.

How one branch is built

The repeatable recipe

Setting up each new branch

The script does the hard work. A person only answers two questions and finishes three simple jobs on‑site.

  1. Connect to the new firewall.

    Plug your computer into the firewall and open the setup script.

  2. Run the script.

    Start provision-branch.py. It greets you and asks for a couple of details.

  3. Answer a few questions.

    Type the staff Wi‑Fi address (for example 192.168.1.1), the guest Wi‑Fi address (for example 192.168.2.1), and how many devices each needs. The script works out the rest.

  4. Let it build.

    The script sets both Wi‑Fi networks, automatic addresses, internet rules, and the plug‑and‑play internet port — all in seconds.

  5. Finish on‑site.

    Enter the internet provider’s username and password, plug in the internet cable, connect the two Wi‑Fi access points, install the security certificate on the office devices, and set up the Head Office VPN. Done.

# Simple way — the script asks you the questions
python scripts\provision-branch.py

# Fast way — give the answers directly
python scripts\provision-branch.py --wifi-ip 192.168.1.1 --clients 25 ^
                                   --guest-ip 192.168.2.1 --guest-clients 25 ^
                                   --hostname FGT-BranchB --yes

The plan

Connecting branches to Head Office (VPN)

A VPN is a private, locked tunnel over the normal internet. It lets every branch talk to Head Office safely, as if they were in the same building.

🏢 One hub, many branches

Head Office is the centre. Every branch builds a tunnel to it. This is called “hub‑and‑spoke”.

📞 Branches “dial in”

Our branches use PPPoE, so their internet address can change. So the branch starts the tunnel, and only Head Office needs a fixed address.

🧭 Unique address per branch

This is the golden rule. If two branches use the same address range, the VPN gets confused. Each branch must be different.

Simple words

Plain‑English glossary

Short, easy meanings for the technical words used in this document.

Firewall
The security box that gives a branch internet and Wi‑Fi and blocks unwanted traffic.
Interface / Port
A socket on the firewall. Some ports face the internet; some face the office.
IP address
A number that names a device on the network, like a house address.
Gateway
The “door” address that devices use to leave their network and reach others.
Subnet /24
One block of addresses. A “/24” block holds about 254 devices.
DHCP
The service that hands out addresses to devices automatically, so no one types them.
NAT
A trick that lets many office devices share one internet connection.
PPPoE
An internet type that needs a username and password from the provider to connect.
WAN
The internet side of the firewall (Wide Area Network).
VPN
A private, locked tunnel over the public internet between two sites.
Hub‑and‑spoke
One centre (Head Office) with many branches connecting to it.
Script
A small program that repeats a set of steps automatically and exactly.
